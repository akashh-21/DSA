# 🔄 Inversion Count using Merge Sort

### 📝 Problem Statement

An **inversion** in an array is a pair `(i, j)` such that `i < j` and `arr[i] > arr[j]`.

**Goal**: Count the total number of such inversions in the array efficiently using the **Merge Sort** technique.

---

### 📌 Example

```text
Input:
arr = [2, 4, 1, 3, 5]

Output:
3

Explanation:
Inversions are (2,1), (4,1), (4,3)

⚙️ Approach
    This problem is solved using a modified merge sort algorithm, which:

    Divides the array into two halves.

    Recursively counts inversions in each half.

    Counts split inversions (where one element is in left half and one is in the right half) during the merge step.

🔧 Functions Explained
    inversion(a, b): Counts cross-inversions between two sorted halves.

    merge(a, b, res): Merges two sorted arrays into one.

    mergesort(v): Performs merge sort and counts total inversions recursively.

🧠 Why Merge Sort Works?
            Because during merging:

            If a[i] > b[j], then all remaining elements in a (from i to end) are also greater than b[j], since both halves are sorted.

            Hence, we can count multiple inversions in one step, making it efficient (O(n log n)).

⏱️ Time and Space Complexity
    Time Complexity: O(n log n)

    Space Complexity: O(n) (for temporary vectors)
