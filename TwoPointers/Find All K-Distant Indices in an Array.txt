# 🔍 Find All K-Distant Indices in an Array

Given an array of integers `nums`, a key, and an integer `k`, find all indices `i` such that there exists an index `j` with `nums[j] == key` and `abs(i - j) <= k`.

---

## 🧠 Intuition

For each occurrence of the `key`, all indices from `i-k` to `i+k` are considered **k-distant**.  
We collect those indices (handling duplicates) and return them in sorted order.

---

## 🛠️ Approach

1. Traverse the array.
2. If an element equals the key:
   - Mark all indices from `i-k` to `i+k` as valid (within bounds).
3. Use a `set` to automatically:
   - Remove duplicates
   - Keep indices sorted
4. Convert the set to a vector and return it.

---

## 🔢 Example

```cpp
Input: nums = [3, 4, 9, 1, 3, 9, 5], key = 9, k = 1
Output: [1, 2, 3, 4, 5, 6]
```

Explanation:
- `nums[2] == 9` → indices [1, 2, 3] are k-distant
- `nums[5] == 9` → indices [4, 5, 6] are k-distant
- Union = {1, 2, 3, 4, 5, 6}

---

## ⏱️ Time and Space Complexity

- **Time Complexity:** O(n × k) in the worst case  
- **Space Complexity:** O(n) for storing indices in the set

---

## ✅ Sample Run

```bash
g++ -o find_k_distant_indices find_k_distant_indices.cpp

```

Output:
