# 🔢 Sum of Subarray Minimums

### 🧩 Problem Statement

Given an array of integers, return the **sum of the minimum value** of every possible contiguous subarray. Since the answer can be very large, return the result modulo **1e9 + 7**.

---

### 📌 Example

    Input: arr = [3,1,2,4]
    Output: 17

    Explanation:
    All subarrays and their minimums:
    [3] -> 3
    [3,1] -> 1
    [3,1,2] -> 1
    [3,1,2,4] -> 1
    [1] -> 1
    [1,2] -> 1
    [1,2,4] -> 1
    [2] -> 2
    [2,4] -> 2
    [4] -> 4

    Sum = 3 + 1 + 1 + 1 + 1 + 1 + 1 + 2 + 2 + 4 = 17


---

### 🚀 Intuition

    Every element `arr[i]` can be **minimum of multiple subarrays**. We want to count:

    - How many subarrays where `arr[i]` is the minimum?

    To do this efficiently, we use **monotonic stacks** to find:

    - `NSI` (Next Smaller Index): how far to the right `arr[i]` stays minimum.
    - `PSI` (Previous Smaller Index): how far to the left `arr[i]` stays minimum.

---

### 🧠 Formula

    The total contribution of `arr[i]` is:

    ```txt
    arr[i] * (# subarrays starting from PSI+1 to i) * (# subarrays from i to NSI-1)
    => arr[i] * (i - PSI) * (NSI - i)
    Sum all such contributions for every index.

⚙️ Algorithm Steps
    Use two stacks to calculate:

    NSI (first smaller on the right)

    PSI (first smaller on the left)

    For each index i:

    Count left = i - PSI

    Count right = NSI - i

    Add arr[i] * left * right to answer

    Return ans % (1e9 + 7)

🛠️ Time & Space Complexity
    Time Complexity: O(n)
    (Each index pushed and popped at most once in the stacks)

    Space Complexity: O(n)
    (Used for stacks and NSI/PSI arrays)

💡 Tips to Remember
    Use Monotonic Increasing Stack to find previous/next smaller.

    For each element, calculate how many subarrays it dominates as min.

    This is like counting contributions, not generating subarrays.
