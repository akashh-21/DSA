# 📊 Next Greater Frequency Element (NGFE)

## 🚀 Problem Statement

    Given an array of integers, find for each element the **next element to its right** which has a **higher frequency** than the current one.  
    If no such element exists, return -1 for that index.

---

## ✅ Example

    ```txt
    Input:  [1, 1, 2, 3, 4, 2, 1]
    Output: [-1, -1, 1, 2, 2, 1, -1]

Explanation:
    Frequencies:
    1 → 3 times  
    2 → 2 times  
    3, 4 → 1 time each

    For:
    - arr[0] = 1 → No right element has freq > 3 → -1
    - arr[2] = 2 → Rightmost '1' has freq 3 > 2 → 1
    - arr[3] = 3 → Right '2' has freq 2 > 1 → 2
🧠 Intuition
    It’s a variation of the Next Greater Element problem. Instead of comparing values, we compare frequencies of the elements.

We use:

    A HashMap to store frequencies.
    A Stack to efficiently find the next greater frequency while iterating from right to left.

🔍 Step-by-Step Logic
    Frequency Map
    Store frequency of each number using HashMap<Integer, Integer>.

    Reverse Traversal
    Process the array from right to left (similar to how next greater problems are approached).

    Use Stack
    Use a stack to track potential next greater frequency candidates.

    While Stack Not Valid
    Pop from stack while top of stack has lower or equal frequency compared to current element.

    Update Answer
    If stack is non-empty, the top is the NGFE (next greater frequency element).

    Push Current Element
    Add current element to the stack for future elements to compare with.

💡 How to Remember
    Think of it like standard Next Greater Element, but instead of comparing arr[i], compare frequency[arr[i]].

🧮 Time and Space Complexity
    Time Complexity: O(n)

    One pass to calculate frequency

    One pass to process with stack

    Space Complexity: O(n)

    For frequency map, stack, and answer array

⚠️ Edge Cases
    All frequencies are the same → all answers will be -1

    Input array has only one element → return [-1]

    Input with repeating and unique values → handled

🧪 Sample Test
    java
    Solution sol = new Solution();
    int[] arr = {1, 1, 2, 3, 4, 2, 1};
    System.out.println(sol.findGreater(arr));
    // Output: [-1, -1, 1, 2, 2, 1, -1]
