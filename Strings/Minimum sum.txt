# 💡 Minimize Sum of Two Numbers Formed From Digits

Given an array of digits, form two numbers using all digits such that their sum is minimized. Return that minimum sum **as a string** to handle large values.

---

## 🧠 Intuition

If you want to split digits into two numbers with the **minimum possible sum**, you should:
- Sort the digits
- Distribute them **alternately** between the two numbers so both numbers grow evenly

### Example:
For input: `[6, 8, 4, 5, 2, 3]`  
Sorted: `[2, 3, 4, 5, 6, 8]`

Distribute alternately:
- `n1 = 2 4 6` → 246  
- `n2 = 3 5 8` → 358  

Now add: `246 + 358 = 604`

---

## 🔢 Approach

1. **Sort** the array of digits.
2. Create two strings: `n1` and `n2`.
3. Alternate digits into `n1` and `n2` (even index to `n1`, odd to `n2`).
4. Perform string-based addition on `n1` and `n2` to avoid integer overflow.

---

## ✨ Features

- Handles large numbers by **string addition**
- Efficient due to sorting + linear pass
- Easy to extend for more complex digit handling

---

## ⏱️ Time and Space Complexity

- **Time:** O(n log n) → Sorting the array  
- **Space:** O(n) → For string building and result
